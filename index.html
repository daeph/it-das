🚀 IT-DAS

Ein Multiple-Choice-Vokabeltest für IT-Begriffe.

📥 Installation

git clone https://github.com/daeph/it-das.git
cd it-das
pip install -r requirements.txt
cd src
python main.py

🎯 Features

  • ✅ Multiple-Choice-Fragen zu IT-Begriffen
  • ✅ 100+ Vokabeln (Python, Git, Docker, SQL)
  • ✅ Statistiken & Highscore
  • ✅ Offline-Nutzung
